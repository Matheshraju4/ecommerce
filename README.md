# ARM Farms ecommerce project

MongoDB conceptual schemas, role and architecture diagrams, and a React/Vite diagram viewer for the ecommerce platform.

## Diagrams

- `demo.erd.json` — current ERD model
- `demo.previous.erd.json` and `democopy.previous.erd.json` — earlier ERD snapshots
- `ARM_Farms_Role_Flows.excalidraw` — customer, wholesale buyer, admin, superadmin, and architecture diagrams
- `ARM_Farms_BRD.pdf` — business requirements source

## View the diagrams

```powershell
cd diagram-studio
npm install
npm run dev
```

Open the URL printed by Vite. See [diagram-studio/README.md](diagram-studio/README.md) for viewer details.
